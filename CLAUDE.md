# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project Overview

This is a **GitHub Pages website** presenting an academic analysis of the *Thresholds in Education* special issue on Generative AI in higher education (Vol. 48, Issue 1, Winter 2025).

**Presenters:** Jasmine Reece & Eryn Shorthll
**Technology:** Plain HTML/CSS/JavaScript (no build process)
**Hosting:** GitHub Pages


```bash

npx http-server
```

## Site Architecture

### Directory Structure
```
/
├── index.html              # Homepage
├── about.html              # About the Issue
├── themes/                 # Key Themes (3 pages)
├── articles/               # Article annotations (8 pages: 4 complete, 4 placeholders)
├── analysis.html           # Analysis & Synthesis
├── questions.html          # Open Questions
├── references.html         # References
├── css/style.css           # All site styles
├── js/navigation.js        # Shared navigation system
└── _config.yml             # GitHub Pages config
```

### Navigation System
- **Centralized:** All navigation is generated by `js/navigation.js`
- **Shared:** Every page includes `<script src="js/navigation.js"></script>` (or `../js/navigation.js` for subdirectories)
- **Dropdowns:** Two dropdown menus (Key Themes, Articles) with hover + click functionality
- **Mobile:** Hamburger menu toggle for small screens

### Color Palette
```css
--primary-navy: #2C5F7C      /* Headers, navigation */
--teal-accent: #4A9B8E       /* Links, highlights */
--sage-background: #E8F3F1   /* Section backgrounds */
--white: #FFFFFF             /* Main background */
--dark-text: #333333         /* Body text */

```

### Typography
- **Headings:** Lato (sans-serif) - Google Fonts
- **Body:** Merriweather (serif) - Google Fonts
- **Line height:** 1.7-1.8 for readability

## File Naming Conventions

- HTML files: lowercase with hyphens (`detection-engagement.html`)
- CSS/JS files: lowercase (`style.css`, `navigation.js`)
- Directories: lowercase, plural where appropriate (`articles/`, `themes/`)

## Key Technical Patterns

### 1. Navigation Updates
To add/modify navigation items:
- Edit `js/navigation.js`
- Update the `navHTML` string
- Changes apply to all pages automatically

### 2. Adding New Pages
When adding a new page:
1. Create HTML file following existing page structure
2. Include CSS: `<link rel="stylesheet" href="css/style.css">` (adjust path for subdirectories)
3. Include JS at end of `<body>`: `<script src="js/navigation.js"></script>`
4. Update navigation in `js/navigation.js` if needed

### 3. Article Page Structure
Each article page should include:
- `<div class="article-header">` - Title, authors, citation
- `<section class="summary">` - Summary content
- Optional: `<h3>Key Contributions</h3>` with `<ul>` list
- `<div class="article-link">` - Link to full article

### 4. Placeholder Article Pattern
Placeholder files include:
- HTML comments with instructions for content addition
- Placeholders: `[ARTICLE_TITLE]`, `[AUTHORS]`, `[FULL_CITATION]`, `[ARTICLE_SUMMARY]`
- Visible placeholder notice that should be removed when content is added
- See `CONTRIBUTING.md` for contributor instructions

## CSS Class Naming Patterns

Key classes used throughout the site:
- `.container` - Main content wrapper (max-width: 900px)
- `.hero` - Homepage header section
- `.section-alt` - Light gray background section
- `.section-highlight` - Sage green background with border
- `.article-header` - Article title/citation area
- `.citation` - APA citation styling
- `.authors` - Author names styling
- `.placeholder` - Placeholder notice (remove when adding content)

## GitHub Pages Deployment

### Enabling GitHub Pages
1. Repository Settings → Pages
2. Source: Select branch (main or feature branch)
3. Save
4. Site will be available at: `https://[username].github.io/[repo-name]`

### Files Excluded from Site
Listed in `_config.yml`:
- README.md
- CONTRIBUTING.md
- CLAUDE.md
- .git/
- .gitignore

## Common Maintenance Tasks

### Adding Content to Placeholder Articles
See `CONTRIBUTING.md` for detailed instructions. Quick summary:
1. Edit placeholder file in `articles/` directory
2. Replace `[PLACEHOLDERS]` with actual content
3. Remove placeholder notice `<div class="placeholder">...</div>`
4. Commit and push

### Updating Site Content
1. Edit the relevant HTML file
2. Test locally: `python -m http.server 8000`
3. Commit changes: `git add [file] && git commit -m "Description"`
4. Push: `git push`
5. GitHub Pages will rebuild automatically (takes 1-2 minutes)

### Adding References
Edit `references.html`:
- Add citations in APA format under "Special Issue Articles" section
- Use `<em>` tags for journal titles
- Maintain alphabetical order by first author
